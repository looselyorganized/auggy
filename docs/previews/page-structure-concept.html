Auggy page structure

How /, /agent, and /console fit together

Private by default, explicit when public

One public home, one optional integration page, one authenticated console.

The creator controls whether integration discovery is public. The real setup surface lives in /console, where auth already distinguishes the operator from visitors.

Config shape

A small config surface keeps the decision readable.

  • publicFrontendUrl unset configured
  • publicIntegration false true
  • creator surface /console
web: publicIntegration: false
web: publicIntegration: true
Creator recognition: public pages do not detect the creator. /console uses loopback access, bearer auth, and the console session cookie.
/ public minimal redirect

Default home

Minimal placeholder while no public frontend is configured.

Redirects to the creator's public app when publicFrontendUrl exists.

  • Agent display name and public-safe purpose, if configured
  • Generic backend-ready message
  • Primary owner link to /console
  • Small developer link to /agent
  • No request examples or runtime posture
/agent 404 public optional

Human integration page

Disabled by default, so creators do not publish integration details accidentally.

Public only when publicIntegration: true.

  • Protocol-level summary only
  • Link to raw agent card JSON
  • Generic auth requirement
  • Minimal request shape without secrets
  • No provider, model, token names, CORS, logs, or diagnostics
/.well-known/agent-card.json 404 or auth public JSON

Machine discovery

Follows the same public discovery policy as /agent.

  • Not exposed when publicIntegration is false
  • Canonical machine-readable agent card
  • Linked from /agent with alternate JSON metadata
/console creator only

Authenticated operator console

The full DX and operations surface. This is where sensitive integration detail belongs.

  • Chat and test runs
  • Identity, skills, knowledge, and credentials
  • /console/integrations with snippets and config guidance
  • Auth posture, CORS, frontend redirect, health, and diagnostics
