# Company application reference

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users and purpose

Engineers integrate their company's existing application with a separately
installed and independently deployed Auggy agent. The visible support screen
demonstrates a signed application session flowing into narrow agent permissions
and an authenticated streaming response.

## Confirmed boundaries

The approved M5 contract owns the product brief. Each company owns its own agent;
this example is not a managed platform. Next.js is an optional consumer. Production
session verification starts unconfigured and fails closed. Customers and support
staff remain public, recognized principals. The synthetic order service records
example effects and moves no money. Conversation history stays in the browser tab.

## Interface

This Operate surface inherits the existing Auggy registry and theme. It provides
a message composer, streamed response, clear failure/interruption states, and an
explicit delivery retry that preserves the operation key. The implementation uses
the approved brief rather than inventing a separate brand or visual world.
